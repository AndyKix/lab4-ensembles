# Лабораторная работа № 4

## Данные и подготовка

Для работы использовал `german.csv` из предыдущей лабораторной. В таблице 1 000 строк и 20 признаков. `Creditability` оставил целевым столбцом: значение 1 считаю положительным классом. Признаки в файле уже записаны числами, пропусков нет, поэтому отдельное кодирование категорий не делал.

Файл данных уже входит в [исходный публичный репозиторий лабораторной](https://github.com/AKlimovUrfu/lab4/blob/main/german.csv); содержимое локального файла совпадает с ним.

Сначала разделил данные на train и test в пропорции 80/20 с `random_state=42` и стратификацией по целевому столбцу. Для выбора модели отложил ещё 20% только от train. Среднее тестовых метрик не использовал при выборе модели.

Для деревьев и ансамблей масштабирование не применял. Для MLP добавил `StandardScaler` в pipeline: он обучается только на переданной ему обучающей части.

## Гипотезы и эксперименты

Проверил Random Forest, Extra Trees, Gradient Boosting, HistGradientBoosting, AdaBoost и MLP. Для лесов ограничил глубину через `min_samples_leaf=3`, использовал 500 деревьев и взвешивание классов. В градиентном бустинге проверил неглубокие деревья с небольшим шагом обучения. Для MLP взял два скрытых слоя размером 32 и 16 нейронов, регуляризацию и раннюю остановку.

Модели выбирались по ROC-AUC на отдельной валидационной части внутри train. На тестовой части затем посчитал итоговые метрики всех заранее заданных вариантов для сравнения. `test_target` не участвовал в обучении или выборе параметров.

## Метрики

В таблице ROC-AUC указан отдельно для валидационной части и теста. Accuracy, Precision, Recall и F1 рассчитаны на test при пороге вероятности 0.5.

| Модель | ROC-AUC validation | ROC-AUC test | Accuracy | Precision | Recall | F1 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Random Forest | 0.7777 | 0.8282 | 0.7750 | 0.8626 | 0.8071 | 0.8339 |
| Extra Trees | **0.7829** | 0.8175 | 0.7550 | 0.8421 | 0.8000 | 0.8205 |
| Gradient Boosting | 0.7308 | 0.8193 | 0.7800 | 0.7791 | 0.9571 | 0.8590 |
| HistGradientBoosting | 0.7608 | **0.8314** | **0.8000** | 0.8165 | 0.9214 | **0.8658** |
| AdaBoost | 0.6649 | 0.7715 | 0.7000 | 0.7000 | 1.0000 | 0.8235 |
| MLPClassifier | 0.6099 | 0.7602 | 0.7500 | 0.7812 | 0.8929 | 0.8333 |

Критерием выбора заранее назначил ROC-AUC на validation, потому что эта метрика оценивает качество ранжирования по вероятностям без привязки к порогу 0.5. По этому критерию выбрал Extra Trees. Полные значения сохранены в `experiment_results.json`.

## Выбранная модель

Выбрал Extra Trees с 500 деревьями, `min_samples_leaf=3` и `max_features="sqrt"`. После выбора модель обучается на всей train-части и проверяется на test. Её итоговый ROC-AUC на test равен 0.8175, Accuracy — 0.7550, F1 — 0.8205.

На тесте HistGradientBoosting показал более высокий ROC-AUC, но он не был выбран, потому что на отложенной валидации результат Extra Trees был лучше. Так тестовая часть осталась проверкой итогового решения, а не способом подобрать модель.

## Выводы и ограничения

Лесные модели дали лучший ROC-AUC среди проверенных вариантов. У AdaBoost и MLP на этом разбиении результат был ниже. Gradient Boosting получил высокий Recall, но при этом точность ниже, чем у Extra Trees и Random Forest.

Выводы основаны на одном разбиении небольшого датасета. Валидационный ROC-AUC может заметно измениться при другом `random_state`, поэтому для более надёжного сравнения стоило бы отдельно провести кросс-валидацию. Категориальные поля в исходном файле уже закодированы числами, и модели воспринимают их как упорядоченные значения.

## Воспроизводимость

Скрипт `run_experiments.py` выполняет сравнение и перезаписывает `experiment_results.json` с измеренными значениями. Использованы seed 42 для train/test и seed 43 для внутренней валидации.

Из корня папки лабораторной запуск:

```bash
python -m pip install -r requirements.txt
python run_experiments.py
```
